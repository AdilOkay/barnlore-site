Privacy policy

Last updated: 4 November 2026

Barnlore uploader is a personal tool run by the owner of the Barnlore YouTube channel on their own computer. It uses the YouTube Data API to upload videos to that channel and to read or change their privacy status.

Data it accesses

Only the Google account of the channel owner, through the OAuth consent the owner grants. It reads and writes videos of that channel. It does not access any other user's data.

Data it stores

An OAuth token, stored on the owner's own computer, used to call the YouTube API. No data is sent to any server other than Google's YouTube API, and nothing is shared with third parties.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google account's third-party access page, or by deleting the token file on the computer.
