Privacy policy

Last updated: 5 November 2026

Barnlore uploader is a personal tool run by the owner of the Barnlore channels on their own computer. It uses the YouTube Data API to upload videos to the Barnlore YouTube channel and to read or change their privacy status. It also uses the Meta Graph API and the Threads API to publish Barnlore's own videos and photos on the Barnlore Facebook Page, on Instagram and on Threads.

Data it accesses

Only the Google account of the channel owner, through the OAuth consent the owner grants. It reads and writes videos of that channel. On Meta, only the Barnlore Facebook Page and the accounts linked to it, through the login of the Page owner, who is the only user of the app. It does not access any other user's data.

Data it stores

OAuth tokens, stored on the owner's own computer, used to call the YouTube, Meta and Threads APIs. No data is sent to any server other than these APIs, and nothing is shared with third parties.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google account's third-party access page, or by deleting the token file on the computer. For Meta, access can be removed from Facebook Settings, Apps and Websites.

Data deletion

The app keeps no data about anyone other than the owner. To delete everything it stores, remove the app from Facebook Settings, Apps and Websites, revoke Google access as above, and delete the token files on the owner's computer. Questions: barnlorefarm@gmail.com.
